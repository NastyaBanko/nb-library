# Nb Library

Library of components

# How to start development

1. Download and install [Node.js](https://nodejs.org/en/download/)
2. Install node modules from package.json with `npm i`
3. Run the app with `npm start` and open `http://localhost:4200/`.

## Running end-to-end tests

Run `npx playwright test --ui` to execute the end-to-end tests

## Used Technologies

1. Modern Angular Architecture (Standalone Components, clean Shared Import)
2. TypeScript (Generics)
3. Playwright
4. Angular Signals
5. Reactive Forms
6. Routing
7. Highcharts library
8. Multi-language support using @ngx-translate/core
9. Custom Components
10. Rest API
11. BEM
12. LESS
